## About

I am a software product builder focused on turning real operational problems into practical systems.

My work has expanded beyond standalone websites into SaaS products, workflow automation, internal business tools, developer tooling, backend systems, reusable engineering capabilities, and full-stack applications.

I care about systems that remain understandable and useful after the first release: clear architecture, controlled change, testing, recovery, security, maintainability, and automation where it removes repetitive work.

## Selected Work

### QRSteady

A mobile-first, trust-focused QR utility platform being developed as a software product.

The project uses a modern TypeScript / Next.js stack with linting, type checking, automated tests, production builds, and documented architecture.

### ORDERra

A backend-first restaurant ordering system built around a Laravel API and a React + TypeScript frontend.

It includes customer ordering flows, dine-in QR sessions, admin operations, simulated payments, support workflows, rider operations, and an operations-focused backend structure.

### Λ PreOTForm

A lightweight local-first utility for preparing monthly overtime and Pre-OT forms from the same schedule data.

Built with static HTML, CSS, and vanilla JavaScript, with dependency-free domain checks for important calendar and form behavior.

### Internal Developer Automation

I also build private developer tooling for repeatable project qualification, verification, controlled execution, evidence capture, and safer development workflows across multiple projects.

## How I Build

I prefer engineering workflows that are:

- Evidence-driven before mutation
- Automation-friendly
- Testable and recoverable
- Secure by design
- Maintainable over time
- Built around clear contracts and boundaries
- Reusable when a capability is proven useful
- Simple at the surface, structured underneath

I prefer proven standards and mature tools where they fit, then build the project-specific gap rather than recreating solved problems unnecessarily.
