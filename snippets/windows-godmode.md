# Windows God Mode Shortcut

A simple Windows shortcut note for opening a centralized Control Panel-style settings view.

This is useful for developers, power users, and anyone who wants quick access to many Windows settings in one place.

---

## Shortcut Name

```
GodMode.{ED7BA470-8E54-465E-825C-99712043E01C}
```

---

## How to Use

1. Right-click on your Windows Desktop.
2. Choose New > Folder.
3. Rename the folder to:
   ```
   GodMode.{ED7BA470-8E54-465E-825C-99712043E01C}
   ```
5. Open the folder.

Windows will display a centralized settings view with many Control Panel options.

---

## Notes

* This is not malware.
* This is not a hacking tool.
* This does not bypass Windows security.
* This is a built-in Windows special folder shortcut.
* It only gives faster access to existing Windows settings.

---

## Use Case

This shortcut can help when checking or managing:
* System settings
* Device settings
* Network options
* User account options
* Backup and recovery settings
* Administrative tools
* Troubleshooting settings
