## Useful Windows Snippet: God Mode Shortcut

This is a Windows shortcut trick that opens a centralized Control Panel-style settings view.

```
GodMode.{ED7BA470-8E54-465E-825C-99712043E01C}
```

## How to use

1. Right-click on your Windows Desktop.
2. Choose New > Folder.
3. Rename the folder to:
   ```
   GodMode.{ED7BA470-8E54-465E-825C-99712043E01C}
   ```
4. Open the folder to access many Windows settings in one place.
